# Rebirth Protocol — Prototype 0.1

GDD v0.2(`../GDD/ROCKMAN_X9_GDD_v0.2.md`)의 시스템을 검증하는 Godot 4.7 프로토타입입니다.
주인공·그래픽은 **오리지널 임시 디자인**(코드로 그린 벡터)이며, 원작 캐릭터·이름·스프라이트·음악은 사용하지 않습니다.

## 실행

```bash
godot --path game
```

에디터로 열기: `godot -e --path game` (또는 Godot 앱에서 `game/project.godot` 열기)

흐름: 타이틀(새 게임 / 이어하기) → 스테이지 선택(훈련 시설 · 프리즘 게코 · 아머 랩) → 출격 멤버 선택 → 스테이지 → 클리어 후 스테이지 선택.
저장 파일: `~/Library/Application Support/Godot/app_userdata/Rebirth Protocol (Prototype)/save.json`

## 캐릭터와 태그 (GDD v0.2 §6 — 오리지널 캐릭터)

기획서의 엑스·제로·액셀 역할을 오리지널 캐릭터로 구현했습니다. 스테이지 전에 2명을 고르고, Tab 으로 그 자리에서 교대합니다.

| 캐릭터 | 역할 | 조작 |
|---|---|---|
| **IX** | 버스터·아머·특수무기 | 3단 차지, 아머 8파츠, 보스 무기 6종(Q/E) |
| **SABLE** | 세이버 | 지상 3연격, 공중 베기, 대시 찌르기, 벽 베기, 패링(V)→반격. 적 탄도 베어 없앨 수 있음. 검술 Q/E: 섬광류(빠름·공중 2회) / 파쇄류(강함·3타가 균열벽 파괴) / 반격류(패링 시간 2배·반격 강화) |
| **ECHO** | 연사·복제 | 8방향 연사(↑↓ 조준), 공중 점프 유지로 호버, V 복제탄 → 처치한 적 데이터로 변신(V): 워커→소형체(1칸 통로 통과), 터렛→3갈래 연사 |

- 교대 직전 0.6초 안에 공격을 맞히면 **태그 콤보**(교대 캐릭터의 무적 돌진).
- 대기 중인 파트너는 2초마다 HP 1 회복. 한 명이 쓰러지면 파트너가 이어받고, 둘 다 쓰러지거나 구덩이·가시에 닿으면 체크포인트부터 다시.

## 특수무기 (GDD v0.2 §5)

보스를 쓰러뜨리면 IX가 무기를 얻습니다(현재 프리즘 게코 → REFRACTION BEAM). 나머지는 F2 디버그 해금으로 시험할 수 있습니다. 무기 에너지 28, 적이 떨어뜨리는 노란 캡슐로 회복.

| 무기 | 보스 | 동작 |
|---|---|---|
| REFRACTION BEAM | 프리즘 게코 | 빠른 광탄, 벽에서 2번 반사 |
| GRAVITY WING | 그래비티 앨버트로스 | 느린 중력 구체: 적 탄을 끌어당겨 지우고 다단 히트 |
| HEAT MIRAGE | 솔라 페넥 | 바닥을 달리는 열파, 관통 |
| FREEZE LANCE | 크라이오 나왈 | 관통 창, 적을 2.5초 동결 |
| CORE DRILL | 테라 팽골린 | 근거리 드릴, 다단 히트, 균열벽 파괴 |
| PULSE RING | 펄스 시카다 | IX 주변으로 퍼지는 고리, 적 탄 제거. **프리즘 게코의 약점**(2.5배 + 패턴 중단, 2.5초 쿨다운) |

## 아머 시스템 (GDD v0.2 §4)

슬롯 4개(HEAD/BODY/ARM/LEG) × 3택(뉴트럴/뱅가드/에어로) = 81조합. 파츠는 스테이지의 캡슐로 해금하고, 켜진 체크포인트나 스테이지 선택의 아머 랩에서 바꿉니다. 프리셋 3칸.

| 파츠 | 뱅가드 | 에어로 |
|---|---|---|
| HEAD | 균열벽·가짜 발판 표시, 일반탄 근거리 유도 | 공중에서도 코어 회복 |
| BODY | 대시 중 피해 50% 감소, 넉백 없음 | 점프 유지로 활공, 공중 피해 25% 감소 |
| ARM | 차지샷이 균열벽 파괴, 풀차지 전체 관통 | 차지샷 3갈래 확산 |
| LEG | 대시 중 재입력으로 2연속 대시, 대시 몸통 공격 | 공중 대시 1회, 공중에서 점프 재입력으로 비행(코어 소모) |

세트: 같은 계열 2파츠(뱅가드 대시 거리 +15% / 에어로 코어 회복 +50%), 하이브리드 2+2(듀얼 코어: 대시 점프 후 공중 대시 +1), 풀세트 필살기(뱅가드 OVERDRIVE RUSH / 에어로 SKY BREAKER).

GDD와 다른 점: 뱅가드 2파츠 효과를 "대시 재사용 단축" 대신 "대시 거리 +15%"로 구현(대시에 쿨다운이 없어서). 전투 중 교체와 얼티밋 아머 IX(히든 보스 보상)는 아직 없음.

## 스테이지

- **훈련 시설** (`levels/test_stage.txt`): 기본 조작 코스 + 파츠 캡슐 7개 + 균열벽 뒤 HP 상한 증가 + ECHO 소형체 전용 통로 안 HP 상한 증가.
- **프리즘 게코** (`levels/prism_gecko.txt`): 반사 레이저(거울로 꺾임), 가짜 발판(뱅가드 HEAD로 보임), 교대로 깜빡이는 홀로그램 발판, 균열벽 뒤 HP 상한 증가, 뱅가드 HEAD 캡슐, 보스전.
- **보스 프리즘 게코**: 바닥·벽·천장을 기어다니다 낙하, 벽에 붙어 굴절탄(분열) 발사, HP 50% 이하에서 홀로그램 분신 + 착지 파편.

맵은 텍스트 파일이라 문자만 바꿔 편집할 수 있습니다(범례는 파일 맨 위).

## 테스트

```bash
godot --headless --fixed-fps 60 --path game -s res://tests/run_tests.gd
```

```bash
godot --headless --fixed-fps 60 --path game -s res://tests/armor_combos.gd
```

- `run_tests.gd` (82개): 이동 수치, 버스터·차지, 무적 시간, 탄-벽 충돌, 가시·레이저, 아머 파츠별 능력, 세트 효과, 필살기, 스테이지 파일, 보스 패턴·페이즈·사망·약점, 교대·다운·태그 콤보, 세이버 스타일별 데미지·패링·균열벽, ECHO 조준·호버·복제·소형체, 특수무기, 저장/불러오기(깨진 파일 포함).
- `armor_combos.gd`: 81조합 전부 규칙 검사 + 81명을 동시에 물리 시뮬레이션해서 점프 높이와 가시 구덩이 대시 점프 사거리 확인.

스크린샷 투어(창이 잠깐 뜸, 저장 파일은 건드리지 않음):

```bash
godot --path game -- --autoshot=/tmp/rp_shots
```
